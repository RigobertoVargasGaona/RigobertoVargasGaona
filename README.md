## 🚀 Proyecto destacado

### Formulario de Incidencias — Quantyc

Formulario web **multi-paso (4 pasos)** para el reporte de incidencias de equipos: de una empresa (datos de la empresa → contacto y ubicación → datos del equipo → descripción y archivos).

- 📋 Validación por paso y completa.
- 📎 Adjuntos hasta **5 archivos** (PDF, JPG, PNG, DOCX, XLSX, RAR) de máx. **10 MB**.
- 🔍 Autocompletado de empresas y catálogos de **marcas** y **categorías**.
- 🏙️ Selector de **ciudades y municipios de Colombia**.
- ⚖️ Aviso de privacidad (Ley 1581 de 2012) y declaración de veracidad.
- ✅ Modal de confirmación con **No. de ticket**.
- 🐳 Desplegado con **Docker + Nginx** con proxy a la API.
